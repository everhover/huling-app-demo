# 乎零 App 交互演示

公网入口：https://everhover.github.io/huling-app-demo/

从 `index.html` 打开统一演示入口，首屏选择四套 onboarding 方案。PC 端左侧提供页面目录，手机端通过左上角按钮展开目录。

- 方案一：登录 → 戒指配对 → 录音教学 → 三栏想法首页。
- 方案二：登录 → 戒指配对 → 录音教学 → 日历与通知权限 → 三栏想法首页。
- 方案三：搜寻并配对绑定戒指 → 登录 → 录音教学 → 三栏想法首页。
- 方案四：搜寻并配对绑定戒指 → 录音教学 → 日历与通知权限 → 注册 / 登录 → 三栏想法首页。
- 方案三和方案四进入戒指配对页后，自动开始搜索，无需再次点击。
- 目录可直接切换「想法 · 健康 · 我的」三栏版本与「Today · 待办 · 日程 · 想法 · 健康」五栏版本。
- 登录输入任意四位数字即可继续。配对搜寻约 10 秒；双击戒指图开始录音，再双击结束。
- 蓝牙、录音、系统权限、云存储和 AI 整理均使用本地模拟数据。刷新演示页面恢复初始状态。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。所有运行依赖均位于 `vendor/`，无需安装或构建。

## 发布

GitHub Pages 从 `main` 分支根目录部署。更新页面后提交并推送到 `main`，静态站点会自动更新。

原有页面仍可通过文件名独立访问；`index.html` 的预览容器不会改变独立页面的布局。目录入口定义在 `demo-portal.js`，预览布局定义在 `demo-portal.css` 和 `demo-preview.css`。

## 可体验流程

- 想法列表 → 每条想法对应详情 → 返回列表；保留列表滚动位置。
- 全部 / 需要确认 / 待办 / 日程互相切换；底栏进入健康、我的。
- 详情、待办、日程、待确认共用事项数据；确认、完成、修改、删除、忽略与撤销跨页保存。
- 详情里的忽略保留条目，点击可恢复；多个待确认项才显示该区块的批量操作。
- 上传中 → 模拟完成上传 → 整理中 → 模拟完成整理；这两个按钮仅推进演示状态。
- 搜索匹配想法内容及关联事项，进入相应详情。
- 待办列表点击条目进入 `TodoDetail.dc.html?id=…`；详情支持编辑、确认与完成，下方关联来源笔记、模拟同主题笔记及相关待办。想法详情里的待办仍在原位展开编辑。
- 健康的睡眠、恢复、活动、趋势详情；我的页面各项设置和设备管理。
- `TodoSchedule.dc.html` 作为旧入口，转到统一的待办页；`?tab=sched` 转到日程页。
- `ThoughtDetailPreview.html` 保留为详情设计的双列对照页面。

`demo-seed.js` 是初始模拟数据；`demo.js` 提供导航和 localStorage 数据保存。演示日期固定为 2026-09-25。真实录音、设备、系统权限、健康和日历接口尚未接入。

通过「我的 → 关于乎零 → 重置演示数据」恢复初始状态。手动刷新任意页面都会恢复整套初始模拟数据，包括编辑、合并、确认、完成、忽略、删除及阅读状态。刷新合并详情会返回初始想法列表。页面间跳转、历史返回和模拟上传整理流程保留操作状态。

## 验证

```sh
node 乎零App界面设计/tests/demo.test.cjs
```

覆盖独立详情内容和状态、关联事项、跨页确认与编辑、忽略恢复、批量处理、撤销、删除恢复及搜索。浏览器检查另外覆盖页面链接、底栏和显示布局。

想法首页左滑进入多选，至少选择两条已整理想法才能合并。合并保留原始录音元数据与转写，归并关联事项，详情可横向切换原录音。当前无真实音频文件：合并和基于原文分段整理均为本地模拟，未接入音频拼接或 AI 重整服务。
